PM Vault & Essential Frameworks

Quick reference guides for Product Management interview preparation and PRDs.

CIRCLES Framework

Design
  • C: Comprehend Context (Goal, Constraints)
  • I: Identify Customers (Personas)
  • R: Report Customer Needs (Pain Points)
  • C: Cut Prioritization (RICE/MoSCoW)
  • L: List Solutions (Creative & Feasible)
  • E: Evaluate Trade-offs (Pros & Cons)
  • S: Summarize Recommendation

BUS Framework

Root Cause
  • B: Business Context (Clarify metrics dropped & timeframe)
  • U: User Segment Isolation (OS, Region, Age, Version)
  • S: Specific Drivers (Internal releases vs External trends)

HEART Framework

Metrics
  • H: Happiness (NPS, CSAT, Satisfaction)
  • E: Engagement (DAU/MAU, Session Frequency)
  • A: Adoption (New Signups, Feature Adoption)
  • R: Retention (Churn Rate, Repeat Visits)
  • T: Task Success (Completion Time, Error Rate)

RICE & MoSCoW Prioritization

Strategy

RICE Score: (Reach × Impact × Confidence) / Effort

MoSCoW: Must-Have, Should-Have, Could-Have, Won't-Have

3-Month BCA to PM Roadmap

Structured month-by-month targets to build a strong PM candidate profile.

Month 1 Foundation

SQL, DSA & PM Basics

  • Learn SQL (JOINs, Aggregations, Subqueries).
  • Solve 30+ basic/medium DSA questions in C++/Java/Python.
  • Read "Decode and Conquer" for PM frameworks.
  • Set up Power BI & build 1 sample dashboard.
Month 2 Application

PM Teardowns & Projects

  • Write 2 Product Teardowns (e.g., Swiggy, Zomato, Spotify).
  • Draft 1 complete PRD in Notion/Google Docs.
  • Build a polished SQL + Power BI Analytics Project.
  • Update Resume focusing on BCA tech + PM leadership.
Month 3 Execution

College Exams & Job Outreach

  • Balance BCA final exam preparation alongside PM prep.
  • Apply to APM, Product Analyst & BA internships.
  • Conduct 10+ mock PM interviews with peers.
  • Cold outreach to 30 PMs on LinkedIn.

Strategic Gateway Roles

If direct APM entry is competitive, target these high-converting roles to transition internally into PM within 6-12 months.

Product Analyst

Focus: Product metrics, SQL, A/B testing dashboards.

BCA Edge: High SQL + data visualization skills.

Business Analyst

Focus: Business requirements, process modeling, client comms.

BCA Edge: Bridging tech capabilities with business needs.

Associate Product Manager (APM)

Focus: Feature ownership, PRDs, user research, sprints.

BCA Edge: Technical background makes sprint planning smooth.

Data Analyst

Focus: Power BI/Tableau, Python analytics, SQL queries.

BCA Edge: Strong database & logic foundations.

Product Operations

Focus: Tooling, workflow optimization, customer feedback loops.

BCA Edge: Process automation & tech tool efficiency.

Product QA / Technical Writer

Focus: Release quality, user stories verification, product docs.

BCA Edge: Understanding edge cases and code architecture.
